# Cursan.Tools

**Cursan.Tools** — это набор утилит для генерации кода в проектах .NET, использующих Entity Framework Core. Инструмент позволяет автоматизировать создание CRUD-операций и связанных с ними форм на основе существующего `DbContext`.

## Возможности

- Генерация CRUD-расширений для сущностей из указанного `DbContext`.
- Генерация форм (Form) для работы с сущностями.
- Использование настраиваемых шаблонов для гибкого управления выходным кодом.
- Работа через удобный интерфейс командной строки (CLI).
- Автоматическое определение имён и пространств имён с помощью вспомогательных классов.

## Установка

После публикации пакета в NuGet его можно будет установить стандартными средствами:

```bash
dotnet add package Cursan.Tools
```

## Использование

Инструмент вызывается из командной строки. Основной синтаксис:

```bash
Cursan.Cli <DbContextName> <Namespace> [OutputDirectory]
```

- `<DbContextName>` — имя класса `DbContext`, для которого генерируется код (обязательно).
- `<Namespace>` — пространство имён, в которое будет помещён сгенерированный код (обязательно).
- `[OutputDirectory]` — каталог для сохранения файлов (необязательно; по умолчанию используется текущий каталог).

**Пример:**

```bash
Cursan.Cli AppDbContext MyApp.Data ./Generated
```

В результате в указанном каталоге будет создан файл с CRUD-операциями для сущностей, входящих в `AppDbContext`.

### Генерация форм

Для генерации форм используется отдельная команда (подробности будут добавлены после стабилизации API). В текущей версии доступна генерация CRUD-расширений.

## Структура проекта

- **Cursan.Tools.Cli** — реализация интерфейса командной строки, включая хост, контекст команд и реестр команд.
- **Cursan.Tools.Generators** — генераторы кода (CRUD-расширения, формы) и связанные с ними шаблоны.
- **Cursan.Tools.Infrastructure** — вспомогательные классы: запись файлов, работа с именами, шаблонизатор.
- **DbContextCrudGenerator** — основной класс для генерации CRUD-кода на основе `DbContext`.

## Требования

- Проект, использующий Entity Framework Core.
